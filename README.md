## 🔥 Featured project

### 📜 [Papyrus](https://github.com/tomasgoico7/papyrus)
**A distributed system that analyzes how well a resume matches a job posting** using AI.
Three independent services (Go · Python · Next.js) talking to each other the way they should.

| | |
|---|---|
| 📬 **Job queue** | Built on PostgreSQL with `SKIP LOCKED`, retries with exponential backoff + jitter and a dead letter queue |
| ⚡ **Two-level cache** | In-process LRU + Redis: a repeated analysis went from **~31 s to < 10 ms** |
| 🔭 **Observability** | Correlation IDs, structured logs, Prometheus metrics and OpenTelemetry tracing |
| 🛡️ **Rate limiting** | Distributed, with Redis + Lua |
| 🤖 **AI** | Match score, missing skills and suggestions generated via LLM |
